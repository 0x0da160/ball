# B.A.L.L.

片手親指操作のローグライト・ブロック崩し（試作）。
設計資料 v0.2 の「第1段階：操作と破壊」を検証するための最小プロトタイプです。

## 遊び方

- `index.html` をブラウザで開くだけで動きます（ビルド・依存ライブラリなし）。
- 画面のどこでも親指でドラッグしてパドルを移動し、指を離すと発射。
- 全ブロックを砕けばクリア。残機 3、尽きたらゲームオーバー。
- 右上の「操作」で親指操作を切り替え（設定は端末に保存）。
  - **A：移動量拡大** — 指の横移動を 2.4 倍してパドルを動かす。
  - **B：基準位置方式** — 指を置いた位置を基準に、左右のずれ量に応じた速さでパドルが動く。
- 「音」で効果音の ON/OFF。iPhone のサイレントスイッチがオンだと Web Audio は鳴りません。
- PC では マウス移動／←→キー、Space で発射、M で操作方式切替。

## ブロック

| 種類 | 見た目 | 耐久 | 得点 |
| --- | --- | --- | --- |
| 通常（岩） | 灰色 | 1 | 10 |
| 硬質（金属） | 暗色＋リベット | 3（当てるたびにひび） | 50 |
| 宝入り | 金色に光る | 2（壊すと財宝獲得） | 500 |

## iPhone 実機での確認

GitHub Pages で公開するのが手軽です：リポジトリの Settings → Pages → Source を
「Deploy from a branch」、ブランチを `main`（ルート）にすると
`https://0x0da160.github.io/ball/` で遊べます。

## 調整値

`game.js` 冒頭の `TUNE`（球速、反射角、パドル幅、A/B の感度など）と `STAGE`（面の配置）を
書き換えて比較できます。数値はすべて試作値です。
