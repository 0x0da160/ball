# B.A.L.L.

片手親指操作のローグライト・ブロック崩し（試作）。
`index.html` をブラウザで開くだけで動きます（ビルド・依存ライブラリ・外部素材なし）。

## 遊び方

- 画面のどこでも親指でドラッグしてパドルを移動し、指を離すと発射。指の横移動は 2.4 倍に拡大してパドルに伝わる（操作A）。
- 全ブロックを砕くと階層突破。「次の層へ」で続行、「帰還する」で終了。層が深いほど球が速く、鉄板が増える。
- 発射できる球の数は **レベルアップ** と **装備** で増える。複数の球は扇状に同時発射され、全部落ちると残機が1減る。
- 「音」で効果音の ON/OFF。iPhone のサイレントスイッチがオンだと Web Audio は鳴りません。
- PC では マウス移動／←→キー、Space で発射。

## 成長

| 種類 | 入手 | 効果の続く範囲 |
| --- | --- | --- |
| レベルアップ | ブロックを壊した経験値。3択から1つ選ぶ（ボール+1、パドル拡張、威力+1、残機+1、球速−8%） | 今回の探索のみ |
| 装備 | 宝入りブロックから発見。ボール・パドル・補助の3枠。同じ装備を拾うと重ね強化 | 階層突破・帰還で確保（端末に保存）。確保前にゲームオーバーになると失う |

装備の例：双子の鉄球・分裂の護符（ボール +1）、重鉄球（威力 +1）、鉱夫の長柄（パドル幅）、防壁の板（残機）、鉱夫のランタン（財宝の得点）。

## ブロック

| 種類 | 耐久 | 得点 |
| --- | --- | --- |
| 岩 | 1 | 10 |
| 鉄板（リベット・錆） | 3（当てるたびにひびが入る） | 50 |
| 宝入り岩（金の鉱脈と宝石） | 2（割れ目から光が漏れる） | 500 |

## 質感と音

- 画像ファイルは使わず、`textures.js` がノイズから高さ・色・鏡面反射を作り、光源から陰影を計算して岩・鉄板・金鉱・木の支柱・鋼球・パドルを焼き込みます。
- `audio.js` は岩の破砕、鉄板の打撃（非調和の固有振動）、金貨、木の支柱、坑道の残響と環境音を波形から合成します。
- 実写テクスチャや録音素材に差し替える場合は、これらのファイルの出力を画像・音声ファイルの読み込みに置き換えます。

## iPhone 実機での確認

Settings → Pages → Source を「Deploy from a branch」、ブランチを `main`（ルート）にすると
`https://0x0da160.github.io/ball/` で遊べます。

## 調整値

`game.js` 冒頭の `TUNE`（球速、反射角、パドル幅、操作感度、経験値、装備の出現率など）、`STAGES`（面の配置）、
`ITEMS`（装備）、`PERKS`（レベルアップの選択肢）を書き換えて比較できます。数値はすべて試作値です。
