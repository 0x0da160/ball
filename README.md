# B.A.L.L.

片手親指操作のローグライト・ブロック崩し（試作）。
`index.html` をブラウザで開くだけで動きます（ビルド・依存ライブラリ・外部素材なし）。

## 遊び方

- **仮想パッド（初期設定）**：画面のどこかに親指を置くと、そこがパッドの中心になる。左右に倒した量でパドルが加速し、慣性で滑る。右上の「パッド」で **ドラッグ**（指の移動を 2.4 倍にしてパドルを直接動かす操作A）に切り替えられる。
- **発射**：球はパドルの上に並んで待つ。タップで1球ずつ撃ち出し、1球目を撃つと残りは 0.32 秒間隔で順番に出る。何もしなくても 2.5 秒で自動発射。
- **加速**：球は何かに当たるたびに 2.2% ずつ速くなる（上限あり）。
- **ジャスト打ち返し**：球がパドルに当たる直前（0.16 秒前）〜直後（0.10 秒後）にタップすると、そのターンだけ球速 ×1.35、ブロックを3枚まで貫通する（強化で増える）。炎の軌跡と閃光が付く。
- **パドルの傾き**：左右に動かすと慣性で傾き、球が当たっても揺れる。傾きは跳ね返る角度に反映される。
- **落下物**：ブロックを壊すと金貨・宝石・装備（遺物）が落ちてくるので、パドルで受け止めて拾う。取り逃すと失う。
- 全ブロックを砕くと階層突破。「音」で効果音の ON/OFF（iPhone のサイレントスイッチがオンだと鳴りません）。
- PC では マウス移動／←→キー、Space で発射・打ち返し。

## 成長

| 種類 | 入手 | 効果の続く範囲 |
| --- | --- | --- |
| レベルアップ | 経験値で3択（ボール+1、パドル拡張、威力+1、残機+1、貫通+1、球速−8%） | 今回の探索のみ |
| 装備 | 落ちてくる遺物を拾う。ボール・パドル・補助の3枠。同じ装備は重ね強化 | 階層突破・帰還で確保（端末に保存） |

装備：双子の鉄球・分裂の護符（ボール +1）、重鉄球（威力 +1）、鉱夫の長柄（パドル幅）、防壁の板（残機）、鉱夫のランタン（財宝の得点）、磁石の籠手（落下物を引き寄せる）。

## ブロック（15素材・最大 3×3 の大きさ）

土、岩、レンガ、木材、ガラス、氷、大理石、鉄板、黒曜石、水晶（自ら光る）、石炭（燃えさし）、銅鉱、金鉱、宝箱、爆薬樽（周囲を巻き込んで爆発・誘爆）。
硬い素材は当てるたびにひびが広がり、大きいブロックほど耐久が高い。

## 面（10種類、11層目からは耐久が上がって繰り返し）

坑道の入口／煉瓦の地下水路／崩れた倉庫／氷の洞／大理石の神殿／水晶の鉱脈／溶岩の縁／金庫室／爆破区画／宝物庫。
面ごとに配置・素材・照明（ランタン、松明、溶岩の照り返し、水晶の光）が変わる。

## 描画と音

- `materials.js`：ノイズから各素材の色・法線・高さ・鏡面・発光のマップを生成（画像ファイルなし）。
- `renderer.js`：WebGL で最大8灯の点光源による陰影、高さマップからの柔らかい影、球とパドルの落とす影、ACES トーンマップ。
- `audio.js`：素材ごとの破砕音（ガラス、レンガ、木、金属、氷、水晶、爆発など）を固有振動とノイズから合成し、坑道の残響をかける。
- 実写テクスチャや録音素材に差し替える場合は、これらの出力を画像・音声ファイルの読み込みに置き換えます。

## iPhone 実機での確認

Settings → Pages → Source を「Deploy from a branch」、ブランチを `main`（ルート）にすると
`https://0x0da160.github.io/ball/` で遊べます。

## 調整値

`game.js` 冒頭の `TUNE`（球速、加速率、発射間隔、パッド感度、傾き、ジャストの猶予、重力など）、`MATS`（素材）、
`STAGES`（面の配置）、`ITEMS`（装備）、`PERKS`（レベルアップ）を書き換えて比較できます。数値はすべて試作値です。
